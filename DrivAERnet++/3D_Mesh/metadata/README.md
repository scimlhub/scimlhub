## Description

The folder contains industry-standard **3D meshes** for all car designs in the **DrivAerNet++ dataset**. Each STL file represents a unique car geometry, including variations across different body types such as **fastback**, **notchback**, and **estateback**. Additionally, this folder includes models with diverse underbody configurations (**smooth for electric vehicles** and **detailed for ICE/hybrid vehicles**) and different wheel setups, providing a comprehensive collection of car geometries for aerodynamic research and design optimization.
