# DrivAerNet++ 3D Mesh Dataset

## Overview

This folder contains industry-standard **3D car meshes** for all vehicle designs included in the **DrivAerNet++ dataset**. The meshes are provided in **STL format**, with each file representing a unique car geometry used for aerodynamic analysis, simulation, and data-driven research.

The dataset is designed to support research in **automotive aerodynamics**, **computational fluid dynamics (CFD)**, and **machine learning–based surrogate modeling**, enabling large-scale studies on vehicle design optimization.

## Mesh Description

Each STL mesh corresponds to a distinct vehicle configuration and includes variations across:

- **Body types**
  - Fastback
  - Notchback
  - Estateback

- **Underbody configurations**
  - Smooth underbody (typical of electric vehicles)
  - Detailed underbody (typical of ICE and hybrid vehicles)

- **Wheel setups**
  - Multiple wheel and rim configurations
  - Variations affecting aerodynamic performance

Together, these variations provide a **comprehensive and diverse collection of car geometries**, suitable for high-fidelity CFD simulations, geometric deep learning, and aerodynamic benchmarking.

## Use Cases

The 3D meshes in this folder can be used for:

- Aerodynamic drag and flow-field analysis  
- CFD simulations and validation studies  
- Machine learning and geometric deep learning research  
- Surrogate modeling for design optimization  
- Parametric studies and design space exploration  
- Automotive aerodynamics benchmarking
