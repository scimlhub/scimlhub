## Description

This dataset contains **high-fidelity pressure field data** stored in **VTK format** on the surfaces of various industry-standard car designs. The pressure fields capture key aerodynamic characteristics and are suitable for detailed analysis, simulation, and data-driven modeling.

Each file provides surface pressure distributions across:
- **Car body types:** fastback, notchback, estateback
- **Underbody configurations:** smooth and detailed
- **Wheel configurations:** multiple industry-standard setups

The dataset supports research in automotive aerodynamics, CFD validation, and machine learning–based surrogate modeling.
